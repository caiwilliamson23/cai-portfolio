Style Tile

This page documents the design system used across the Cassius Design Studio site: the palette, the typographic scale, and the spacing rules, so every page pulls from the same set of decisions.

Palette

Primary, Deep Indigo #232946. Header background and heading color. White text on this background checks at 14.2 to 1, well above the 4.5 to 1 minimum.

Neutral text #1c1c1e on neutral background #faf9f7. Body text and page background. Checks at 16.2 to 1, the safest pairing in the palette.

Accent, Burnt Orange #b5461f. Reserved for the call-to-action button only, never as body text. White text on this background checks at 5.4 to 1, above the 4.5 to 1 minimum.

Type Scale

Heading 1, 2.5rem (40px)

Heading 2, 1.75rem (28px)

Heading 3, 1.25rem (20px)

Body text, 1rem (16px)

Spacing

  • main: max-width 800px, centered with margin: 0 auto, padding 40px top and bottom, 20px left and right.
  • Every h2: margin-bottom 8px, keeps a heading close to the paragraph it belongs to.
  • Every p: margin-bottom 32px, separates one topic from the next.
  • The call-to-action button: padding 16px top and bottom, 32px left and right, plus margin-top 24px to separate it from whatever sits above it.
